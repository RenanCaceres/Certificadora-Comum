# Gabarito - Caderno de Missoes II: Programacao em C (Fases 3 e 4)

Solucoes de referencia das 10+10 questoes e dos 3 desafios. Cada solucao e uma
resposta possivel; variacoes com o mesmo comportamento tambem estao corretas.

## Estrutura
- `Fase3-Lacos-de-Repeticao/`: Q1 a Q10 (while, do while, for, contador, break, continue)
- `Fase4-Modularizacao/`: Q1 a Q10 (procedimentos, funcoes, parametros, retorno)
- `Desafios/`: D1 (lacos aninhados), D2 (base secreta - do while + contador), D3 (caixa eletronico - menu + funcoes)

## Como compilar e executar
```
gcc -Wall -Wextra arquivo.c -o programa
./programa          # Windows: programa.exe
```
