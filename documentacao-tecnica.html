1. Introdução

O projeto Try, Catch & Learn consiste no desenvolvimento de Recursos Educacionais Abertos (REA) voltados ao ensino dos fundamentos da programação na linguagem C. A proposta é disponibilizar materiais didáticos acessíveis, organizados e gratuitos, destinados principalmente a estudantes iniciantes e ao público externo à universidade.

Para isso, foi desenvolvida uma plataforma web que reúne conteúdos teóricos, apresentações, exercícios, resoluções comentadas, videoaulas e um projeto integrado em C. Os materiais foram organizados em seis fases de aprendizagem, permitindo que os estudantes avancem gradualmente pelos principais conceitos da programação.

Esta documentação apresenta os aspectos técnicos do projeto, incluindo suas tecnologias, organização do repositório, estrutura da aplicação web, funcionamento dos recursos e orientações para execução e manutenção.

2. Objetivos do sistema

O objetivo principal é disponibilizar uma plataforma de apoio ao aprendizado de Fundamentos da Programação em C, centralizando os recursos educacionais produzidos durante o projeto.

Entre os objetivos específicos estão:

  • Organizar os conteúdos em uma sequência progressiva de aprendizagem.
  • Disponibilizar materiais teóricos e apresentações das seis fases do curso.
  • Reunir exercícios práticos e seus respectivos gabaritos em C.
  • Disponibilizar videoaulas e materiais complementares.
  • Apresentar um projeto integrado que demonstre a aplicação dos conceitos estudados.
  • Permitir o acesso público aos recursos por meio do GitHub Pages.

3. Visão geral da solução

A solução é composta por dois elementos principais:

3.1. Plataforma web

O portal Try, Catch & Learn funciona como ponto central de acesso aos materiais. Ele apresenta a proposta do projeto, a trilha de aprendizagem, os materiais disponíveis, informações sobre a equipe e a área de videoaulas.

A aplicação foi desenvolvida utilizando HTML, CSS e JavaScript, sem depender de um servidor de aplicação próprio para disponibilizar suas páginas estáticas.

3.2. Repositório educacional

O repositório GitHub armazena os arquivos que compõem o projeto, incluindo os códigos-fonte da plataforma, documentos em PDF, apresentações, exercícios resolvidos, videoaulas e o Projeto Integrado em C.

Essa organização permite que os materiais sejam consultados individualmente ou por meio da plataforma web.

5.2. Descrição dos diretórios

Conteúdo-Teórico: reúne o e-book, os materiais teóricos referentes às fases do curso e os recursos complementares utilizados durante o aprendizado.

Gabarito-Exercícios: armazena as resoluções dos exercícios propostos, organizadas de acordo com as seis fases. Também contém desafios integradores e exemplos extras.

Slides: contém as apresentações utilizadas nas aulas e os códigos em C correspondentes aos exercícios demonstrados nos slides.

Projeto-Integrado: reúne a aplicação desenvolvida em C para demonstrar, de maneira prática, a utilização dos conceitos estudados ao longo das fases.

assets: armazena os recursos visuais utilizados pela plataforma, como imagens e elementos gráficos.

css: contém os arquivos responsáveis pela apresentação visual e pelas animações da plataforma.

js: contém os scripts responsáveis pelos comportamentos e recursos interativos do site.

aulas: diretório destinado aos arquivos de videoaulas.

6. Desenvolvimento da plataforma web

6.1. Página principal

O arquivo index.html representa a página principal da plataforma. Ele organiza as seções de apresentação do projeto, trilha de aprendizagem, materiais educacionais, equipe e videoaulas.

A navegação é estruturada por links internos que direcionam o usuário às diferentes seções da página. Também existe uma navegação específica para dispositivos móveis.

6.2. Estilização

Os arquivos CSS são responsáveis pela identidade visual da plataforma, incluindo cores, tipografia, espaçamentos, organização dos elementos, adaptação a diferentes tamanhos de tela e animações.

O arquivo css/styles.css concentra os estilos principais, enquanto css/animations.css reúne os efeitos de animação.

6.3. Interatividade

O arquivo js/main.js é incluído na página principal e concentra a lógica JavaScript utilizada pela plataforma.

Entre os recursos presentes na interface estão a navegação móvel e a área de videoaulas, que permite selecionar uma aula, abrir o player e acessar materiais teóricos e exercícios relacionados.

6.4. E-book

O arquivo ebook.html contém a estrutura da versão online do e-book de Fundamentos da Programação em C. O documento utiliza HTML e CSS para organizar o conteúdo em formato adequado à leitura e à apresentação em páginas.

8. Projeto Integrado em C

O Projeto Integrado tem como finalidade demonstrar a aplicação prática dos conceitos apresentados durante o curso.

A aplicação consiste em um sistema de cadastro de pessoas, desenvolvido em linguagem C. Sua evolução acompanha os conteúdos estudados, incorporando estruturas de decisão, repetição, modularização e variáveis compostas.

O código-fonte principal está localizado em Projeto-Integrado/main.c, acompanhado de um arquivo README com informações específicas sobre a aplicação.

8.1. Compilação e execução

Para compilar e executar o projeto, é necessário possuir um compilador C compatível, como o GCC. Após clonar o repositório, podem ser utilizados os seguintes comandos:

gcc -Wall -Wextra Projeto-Integrado/main.c -o projeto_integrado

Para executar no Linux ou macOS:

./projeto_integrado

No Windows, utilizando um ambiente com GCC configurado:

projeto_integrado.exe

Os exercícios individuais também podem ser compilados separadamente, utilizando seus respectivos caminhos dentro do repositório.

9. Publicação e hospedagem

A plataforma web é disponibilizada por meio do GitHub Pages, serviço de hospedagem integrado ao GitHub que permite publicar páginas estáticas diretamente a partir de um repositório.

O endereço público da plataforma é:

https://renancaceres.github.io/Certificadora-Comum/

Para atualizar a publicação, os arquivos modificados devem ser enviados ao repositório remoto. A atualização do site ocorre conforme a configuração de publicação do GitHub Pages.

10. Testes e validação

A validação do projeto deve considerar tanto a plataforma web quanto os materiais e programas disponibilizados.

Os principais pontos de verificação são:

  • Abertura e navegação entre as seções da página.
  • Funcionamento dos links para os materiais e arquivos PDF.
  • Acesso aos diretórios e arquivos do repositório.
  • Reprodução das videoaulas disponibilizadas.
  • Funcionamento da navegação em diferentes tamanhos de tela.
  • Compilação e execução dos exercícios em C.
  • Compilação e execução do Projeto Integrado.
  • Verificação dos caminhos dos arquivos utilizados pela plataforma.
Os resultados dos testes devem ser registrados após a execução das verificações, indicando eventuais problemas encontrados e as correções realizadas.

11. Manutenção e evolução

A manutenção do projeto deve preservar a organização dos diretórios e a correspondência entre os materiais educacionais e as referências disponibilizadas na plataforma.

Para adicionar ou atualizar conteúdos, recomenda-se:

  1. Inserir os arquivos no diretório correspondente à sua finalidade.
  2. Manter a organização dos materiais por fase.
  3. Atualizar os links no HTML quando novos arquivos forem disponibilizados.
  4. Verificar os caminhos dos arquivos após qualquer alteração na estrutura.
  5. Testar a navegação e os recursos interativos.
  6. Enviar as alterações ao GitHub e verificar a publicação no GitHub Pages.

A estrutura modular dos arquivos permite que os materiais e recursos sejam atualizados sem a necessidade de reconstruir toda a plataforma.
