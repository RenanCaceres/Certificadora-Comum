## ⚙️ Como compilar e executar

Todos os 21 códigos foram testados rigorosamente e compilam sem avisos (`0 errors, 0 warnings`):

```bash
# Exemplo 1: Compilar exercício da Fase 1
gcc -Wall -Wextra Fase1-Primeiros-Passos/m01_loja_de_pocoes.c -o f1_ex1

# Exemplo 2: Compilar exercício da Fase 4
gcc -Wall -Wextra Fase4-Modularizacao/m03_dano_no_chefao.c -o f4_ex3

# Executar no Linux / macOS
./f1_ex1

# Executar no Windows
f1_ex1.exe
```
