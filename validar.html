Consultar por Dados do Certificado

Digite os dados exatamente como impressos no documento (ou escaneie o QR Code do certificado para preenchimento automático).

🔐
Como funciona a validação sem servidor: O código impresso no certificado é uma assinatura criptográfica determinística (SHA-256) gerada a partir do Nome, CPF, Data de Conclusão e Carga Horária (10h). Qualquer alteração de um único caractere invalida imediatamente o documento. Por privacidade (LGPD), o resultado exibe o CPF de forma parcialmente ocultada.
